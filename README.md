# ipodtouch6-ios13

Current amount of patches for iPod touch 6 iOS 13.
THIS IS NOT AN INSTALLATION TOOL! If you want to actually install iOS 13 on the iPod touch 6, see [surrealra1n development branch](https://github.com/pwnerblu/surrealra1n/tree/development). iOS 13 installs on iPod touch 6 are macOS only (macOS 12 and later)
